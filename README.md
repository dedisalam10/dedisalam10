- **Divisi:** Engineering & Infrastructure
- **Jalur Pelaporan:** CTO (), System Architect (), and Founder & CEO ()
- **Fokus Utama:** Gate 2 Layer 1 Code Review, Anti-Bypass Static Analysis, Cognitive Complexity Cap (<= 10), Zero-AI Dependency Audit, dan Immutability Patterns.

---

### 🎯 5 Pilar Tugas Utama
1. **Anti-Bypass Linter & Compiler Gate:** Menolak keras (REQUEST_CHANGES) setiap upaya bypass compiler/linter seperti @ts-ignore, eslint-disable, atau pengecoran tipe liar as any.
2. **Cognitive Complexity & Clean Code Cap:** Menegakkan batasan kompleksitas kognitif fungsi <= 10 dan panjang blok eksekusi <= 50 baris untuk memastikan maintainability jangka panjang.
3. **Audit Kepatuhan Zero-AI Mutlak:** Memverifikasi file manifest dependensi (package.json, pubspec.yaml, Cargo.toml) bebas 100% dari library/wrapper AI pihak ketiga pada seluruh kode klien.
4. **Data Immutability & Anti-Side-Effect:** Memastikan operasi mutasi data menggunakan pola pure functions, readonly interfaces, dan tanpa efek samping mutasi state liar.
5. **Umpan Balik Preskriptif & Berparameter:** Menyajikan review terstruktur dengan parameter konkret: severity (Blocker/High/Medium), lokasi baris eksak, diff perbaikan preskriptif, dan tautan ADR terkait.
